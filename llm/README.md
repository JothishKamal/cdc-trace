# Code-reading LLM baseline (run on a local GPU)

`prompts.jsonl` holds 3,580 prompts: each one shows a model a report claim and the full
source of one code element (body included) and asks YES or NO. They cover 7,235
claim-element pairs (`pairs.jsonl`) from the authored and the independent corpus.

On the machine with the GPU (Windows, macOS or Linux):

1. Install Ollama from https://ollama.com, then in a terminal:
   `ollama pull qwen2.5-coder:7b`
2. In this folder: `python llm_run.py`
   (try `python llm_run.py --limit 20` first; on an RTX 3060 the full run should take
   roughly 20 to 40 minutes, and it resumes where it stopped if interrupted)
3. Send back `answers.jsonl` and `run_info.json`.

Then `python experiments/llm_score.py` in the repository writes `results/llm.json`.

Decoding is greedy (temperature 0, top_k 1, fixed seed) and `run_info.json` records the
model digest, so the run can be repeated. `prompts.jsonl` is regenerated by
`python experiments/llm_export.py`.
